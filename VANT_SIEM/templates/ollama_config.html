Instalación de Ollama
# Instalar Ollama
curl -fsSL https://ollama.ai/install.sh | sh

# Descargar modelo recomendado
ollama pull llama3.2

# Iniciar servicio
ollama serve
Verificación
# Verificar que Ollama está ejecutándose
curl http://localhost:11434/api/tags

# Listar modelos disponibles
ollama list

# Probar modelo
ollama run llama3.2 "Hola"
Recomendaciones
  • Asegúrese de que Ollama esté ejecutándose antes de usar las funciones de IA
  • El modelo llama3.2 es recomendado por su balance entre velocidad y calidad
  • Una temperatura de 0.3 proporciona respuestas consistentes y útiles
  • Monitoree el uso de recursos del sistema cuando use IA intensivamente
